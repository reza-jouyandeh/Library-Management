# Customer Requirements

## Customer
The customer is a library administrator who needs a simple system to manage library operations.

## User Needs
- Add and manage books.
- View available books.
- Register library members.
- Record borrowed books.
- Track returned books.
- Find books by title or author.

## Functional Requirements
1. The system must allow the administrator to add new books.
2. The system must display the list of available books.
3. The system must store customer information.
4. The system must record book borrowing and returning.

## Non-Functional Requirements
- The system should be easy to use.
- The information should be organized.
- The system should respond quickly.

## Expected Result
A simple Library Management System that helps the administrator manage books and library members efficiently.
