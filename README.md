# Library Management System

## Introduction
This project is a simple Library Management System designed to manage books and customers in a library.

## Project Goals
- Manage library books
- Register customers
- Track borrowed and returned books
- Organize library information

## Project Features
- Add new books
- View available books
- Register new customers
- Manage book borrowing and returning

## Project Structure
- `README.md`: Project introduction and documentation
- `__init__.py`: Python package initialization
- `Team.md`: Team information
- `Customer.md`: Customer requirements
- `Plan.md`: Project planning
- `Execute.md`: Project execution
- `Close.md`: Project closure
